# 09. 개인정보·보안·아동 영상 보호

## 기본 원칙
- 아동 데이터와 영상은 고위험 개인정보로 취급: 최소 수집, 목적 제한, 명시적 동의, 기본 비공개.
- TLS, DB/객체 저장소 암호화, 비밀 관리 서비스, 사용자별 인증.
- 영상 스트리밍은 별도 단기 토큰; URL 공유로 무제한 열람되지 않게 한다.
- 원본 영상/오디오는 **기본 미저장**; 필요 시 명시적 동의와 최소 범위의 스냅샷만 제한 보관.
- 모델 학습에 아동 데이터를 활용하는 것은 별도 동의·정책 검토가 필요하다.

## 역할/접근
- 개인/기관 데이터 범위 분리. 기관 직원 전체가 아이를 열람하는 설계 금지.
- 보호자가 시터 초대 시 아이·기간·권한을 선택.
- 다중 워크스페이스 사용자의 권한 혼합 금지.
- 로그에 이름/생년월일/사진 URL/민감 추천 원문/토큰 기록 금지.
- 아이 상세 조회, 스트림 발급, 공유 및 철회, 권한 변경에 감사 로그 남김.

## 보관/삭제 정책(초안, 확정 필요)
- 세션·초대 토큰: 만료/철회 후 단기 정리.
- 센서 원시값: 짧은 기간 또는 집계 후 삭제.
- 이벤트·루틴·돌봄 피드백: 사용자 약관에 정한 기간; export/삭제 요청 지원.
- 감사 로그: 운영·법적 보존 의무에 맞춘 제한 기간.
- 삭제 요청은 큐/캐시/백업까지 전파하는 절차 필요.
- 기관 연결 해제는 개인 기록 삭제와 별개의 작업.

## 안전성
- 시스템은 보호자의 현장 확인을 대체하지 않음.
- 알림 전달 보장·의학적 진단·영아 돌연사 예방 효능을 암시하지 않음.
- 법규/규정, 기관 운영 계약, 미성년자 보호 동의, 보관기간은 서비스 출시 국가에 맞게 법률 검토 필수.
