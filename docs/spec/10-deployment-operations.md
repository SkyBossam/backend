# 10. 배포·운영

## 환경
`local`, `staging`, `production`; 분리된 DB와 토큰 키 사용.
CI: 정적 분석 → 단위/통합 테스트 → DB 마이그레이션 테스트 → 배포.
데이터베이스 변경은 expand-and-contract 패턴으로 하위 호환 유지.

## 핵심 SLO (초안)
- API 월 가용성 목표 99.9% (모니터링 기능에 대한 별도 정의 필요).
- 위험 감지→알림 지연 p95를 관측하며 목표치는 실환경 측정 후 결정.
- 실시간 연결 끊김/추론 중단/큐 지연/푸시 실패 지표 제공.
- 안전 관련 알림은 전송 실패가 있으므로 전달 보장을 주장하지 않음.

## 장애/복구
- 추론 서버 장애: 추론 불가 표시, 위험 '안정'으로 대체 금지.
- 카메라 끊김: `connection_lost` 이벤트, 모니터링 `offline`.
- 브라우저/SSE 끊김: 커서 기반 이벤트 누락 재조회.
- DB/큐 장애: 재시도, DLQ, outbox 재발행, 멱등 처리.
- 권한 저장소 오류: fail closed(기본 접근 거부).
- 이력 백업 암호화 및 정기 복원 훈련.

## 성능
- 이벤트 테이블 날짜별 파티셔닝 검토.
- `workspace_id`, `child_id`, `started_at` 기준 주요 인덱스.
- 실시간 영상은 API 서버 경유 프록시 스트리밍 대신 미디어 서버 사용.
- 분석 원시 데이터는 별도 저장/집계로 OLTP 부하와 격리.
