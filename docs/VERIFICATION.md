# 로컬 검증 결과

검증 환경: Windows · Temurin Java 21.0.13 · Maven 3.9.11 · PostgreSQL 16.15. 실행 날짜: 2026-11-01 (Asia/Seoul).

`mvn verify`: **통합 테스트 25개, 실패 0, 오류 0**. 실제 PostgreSQL 초기화, Flyway 마이그레이션 3개 적용, 운영용 Spring Boot JAR 패키징을 완료했습니다.

확인한 주요 시나리오:

- 가입 시 개인 공간 생성, 토큰 해시 저장, JWT 세션 폐기·refresh 재사용 탐지.
- 기관 멤버십만으로 아이 열람 불가, 다른 기관/아이 ID 교체 공격 차단.
- 시터의 아이별 기능 제한, 이메일 소유 확인, 초대 만료·수락 멱등성·권한 철회.
- 권한 회수 후 열린 SSE 연결 종료, 기존 스트림 토큰 무효화.
- 기관 공유의 명시적 대상 권한, 기록 자동 혼합 방지, 공유 철회 후 접근 차단.
- 오프라인·가려짐·분석 지연·낮은 신뢰도는 `unknown/unverifiable`; 센서 미연결은 `null`.
- 읽음·사용자별 확인·현장 해결 분리, `needs_help`는 `checking` 유지.
- 추천 대기·실패 시 기본 안내, 타 이벤트 행동 ID 거부, 미시도와 반응 분리.
- 동시 피드백 요청의 단일 저장, 동일 키의 다른 본문 거부.
- 오프라인 중 생성한 알림의 재조회, 발송 시 수신 권한 재검사.
- outbox 5회 실패→DLQ→재등록→단일 전달.
- 위험도 우선 대시보드, 빈 요약의 `null`, 커서의 중복 방지·범위 검증.
- 루틴 완료/되돌리기/삭제와 다른 아이 루틴 수정 차단.
- 데이터베이스 복합 외래 키의 기관 혼합 차단.

실제 로컬 HTTP 서버도 시작했습니다. `/actuator/health`는 `UP`, Swagger `/docs`는 200, OpenAPI는 3.1.0이며 47개 경로·54개 연산을 제공합니다. `clients/aicoo-client.ts`는 TypeScript 5.8의 strict/noEmit 검사를 통과했습니다.

외부 카메라·AI 추론·실제 SMTP·모바일/브라우저 푸시·Docker 배포·대규모 부하 검증은 수행하지 않았습니다. 이 경계의 현재 동작과 설정은 README 및 OPERATIONS 문서에 구분했습니다.
